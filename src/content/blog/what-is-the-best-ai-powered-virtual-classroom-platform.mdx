### 1. The Multimodal Agent Pipeline: Moving Beyond the LLM Wrapper

Early implementations of virtual classrooms relied on decoupled, post-hoc AI processing: audio was captured via standard Selective Forwarding Units (SFUs), routed to external Speech-to-Text (STT) APIs, and then fed into a generic Large Language Model (LLM) to generate static summaries.

In 2026, premier platforms run on native, multimodal agentic frameworks. These platforms ingest raw WebRTC audio, video, and interaction streams simultaneously to perform sub-100ms inferencing.

```
[Raw Audio/Video/Text Streams] 
       │
       ▼
[Edge Ingestion & Zero-PII Tokenization] 
       │
       ├──► [Edge Prosody & Gaze Analyzers (Sub-50ms)]
       │
       ▼
[Orchestration Engine + Canonical Course Vector Graph]
       │
       ▼
[Autonomous Pedagogical Agents: Socratic Interventions / Real-Time Remediation]
```

#### Low-Latency Multimodal Ingestion
The best platforms integrate directly with Edge-SFUs. Instead of waiting for full conversational turns, the platform tokenizes audio prosody (pitch, cadence, hesitation), textual input (chat, shared code, virtual whiteboards), and visual metrics (gaze stability, facial expression kinematics) simultaneously. 

#### Retrieval-Augmented Generation (RAG) on Canonical Course Graphs
Real-time answers cannot rely on open-web parametric memory. Top-tier platforms construct dynamic, vectorized knowledge graphs from the institutional syllabus, textbooks, and verified lecture materials. When a student expresses confusion, the platform cross-references the student's real-time input against this canonical graph to produce pedagogically anchored hints rather than unchecked generative answers.

#### On-Device & Edge-Inference Processing
Raw biometric data—such as eye gaze, facial expressions, and vocal resonance—never leaves the local client. The platform processes these signals directly on the user's hardware or at a sovereign edge POP (Point of Presence), translating raw video into an abstract, numerical engagement vector before any network transmission occurs.

#### Ephemeral Context Windows & Zero-Retention Agreements
Leading enterprise platforms utilize zero-retention LLM instances. Student-generated text, audio, and visual inputs are held in memory exclusively for the duration of the active inference window (e.g., answering a question or generating a breakout prompt) and are instantly purged. User data is strictly isolated from model retraining datasets.

#### Explainable Algorithmic Auditing
Platforms must maintain transparent decision logs. If an AI system flags a student for academic disengagement or dynamically assigns a lower-tier practice module, it generates an auditable, deterministic log explaining the inputs that triggered that adaptation. This protects institutions against algorithmic bias and supports transparent accessibility reviews.
